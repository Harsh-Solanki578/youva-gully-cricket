# 🏏 YOUVA Gully Cricket

**YOUVA Gully Cricket** is a native Android application developed to make gully cricket scoring **simple, fast, and digital**.

The application allows users to set up a cricket match, record every ball, automatically calculate scores and targets, analyze the match, and save match history. It is designed especially for **local and casual gully cricket matches**, where traditional manual scoring can be difficult.

---

## 🎯 About the Project

In gully cricket, matches are often played with customized overs and local rules. Keeping track of runs, wickets, overs, targets, and match results manually can lead to calculation mistakes.

**YOUVA Gully Cricket** provides a convenient digital scoring solution that handles these calculations automatically while keeping the interface easy to use.

The application supports standard cricket scoring concepts along with customizable options suitable for gully cricket.

---

## ✨ Features

### 🏏 Match Setup

- Create a match between two teams
- Select the number of overs
- Select toss winner
- Select batting or bowling decision
- Start and manage the match

### 🔢 Ball-by-Ball Scoring

- Record runs for every ball
- 0, 1, 2, 3, 4 and 6 runs
- Wicket recording
- Automatic over and ball counting
- Automatic score and wicket calculation

### ⚡ Extra Runs

- Wide ball support
- Configurable wide runs
- Wide re-bowling
- No-ball support
- Configurable no-ball runs
- No-ball re-bowling
- Free hit after no-ball

### 🎯 Match Calculation

- Automatic innings score calculation
- Automatic target calculation
- Required runs calculation
- Required Run Rate (RRR)
- Current run rate
- Automatic match result
- Winner declaration

### 📊 Match Analysis

The application provides visual and analytical information about the match, including:

- Run Rate Graph
- Worm Graph
- Manhattan Graph
- Projected Score
- Win Probability for both teams
- Partnership Analysis
- Boundary Analysis

### ↩️ Scoring Control

- Ball-by-ball history
- Undo previous scoring action
- Review previous scoring events
- Reset match when required

### 💾 Match History

Completed matches can be stored and viewed later.

Users can review information such as:

- Teams
- Overs
- Scores
- Wickets
- Match result
- Match date and time

### 📄 PDF Match Report

The application can generate a PDF report containing important match information and analysis for saving and sharing.

### 🌓 Theme Support

- Light Theme
- Dark Theme

## 🛠️ Technologies Used

The application is developed using modern native Android technologies:

- **Kotlin** — Main programming language
- **Jetpack Compose** — Modern Android UI toolkit
- **Android Studio** — Development environment
- **Room Database** — Local data storage
- **Moshi** — JSON data conversion
- **Kotlin Coroutines** — Asynchronous operations
- **ViewModel** — Application state and logic management
- **Compose Canvas** — Graph and chart rendering
- **Android PdfDocument API** — PDF report generation
